# kividb_agent_memory_store (Resource)

An agent memory store on a database: what an AI agent should remember, within a
conversation and across them. Working memory is a session's recent messages and
a running summary; long-term memories are facts and events kept per actor and
searched by meaning or by words.

```terraform
# No hosted models: your application sends its own vectors, and keyword search
# works without any. Sessions are kept but not summarized, and long-term
# memories are the ones your application adds.
resource "kividb_agent_memory_store" "support" {
  instance_id    = kividb_instance.cache.id
  name           = "support"
  embed_provider = "none"
  llm_provider   = "none"
  dimensions     = 384
}

# With models: OpenAI embeddings, and Anthropic summarizing sessions and
# extracting long-term memories from them, with your keys.
resource "kividb_agent_memory_store" "assistant" {
  instance_id    = kividb_instance.cache.id
  name           = "assistant"
  embed_provider = "openai"
  embed_model    = "text-embedding-3-small"
  embed_api_key  = var.openai_api_key
  dimensions     = 1536
  llm_provider   = "anthropic"
  llm_model      = "claude-haiku-4-5"
  llm_api_key    = var.anthropic_api_key

  session_ttl_seconds = 86400

  custom_types = [{
    name        = "product"
    description = "Which of our products the user uses or is asking about."
  }]
}

# Destroying either one deletes every session and memory in it.
```

## Destroying deletes the memories

Sessions and memories live in the database itself. Destroying the resource
deletes every session and every memory in the store, and so does anything that
replaces it: a different `instance_id` or `name`. The database must be running
for the delete to go through.

Terraform manages the store's settings only. Your application adds messages,
adds and searches memories, and recalls context through the API.

Agent memory is not available on sharded databases; the API refuses to create a
store on one.

## What changes in place

Everything except `instance_id` and `name` changes in place. `dimensions` can
change only while the store holds no long-term memories; with memories in it the
API refuses the change. `keep_recent` must stay below `summarize_after`, which is
checked at plan time.

## Models

`embed_provider` turns memories and queries into vectors; with `none` your
application sends its own vectors, and keyword search needs none. `llm_provider`
summarizes long sessions and extracts long-term memories in the background,
`extraction_delay_seconds` after a session's last new message; with `none`,
nothing is summarized or extracted.

Both API keys are stored encrypted and never returned, so each is kept in state
as you gave it, and a key changed in the console is not detected. Leaving one
out of a later apply keeps the stored key, as long as its provider stays the
same. Model calls bill your account with that provider.

`dedupe_threshold` is computed when left out: the API uses 0.92 when the store
is created, and a later apply without it keeps whatever the store has.

## Schema

### Required

- `dimensions` (Number) The length of every vector in the store, 2-8192. Changes in place only while the store holds no long-term memories; with memories in it the API refuses.
- `embed_provider` (String) Where memories and queries are turned into vectors. `none`: your application sends its own vector with each memory and each semantic search, and keyword search works without one. `openai` or `openai_compatible`: that service, with your key. Changes in place.
- `instance_id` (String) The database the store lives in. Changing it makes a new, empty store there and deletes this one with everything in it.
- `llm_provider` (String) The language model that summarizes long sessions and extracts long-term memories from them in the background. `none`: no model is called; sessions are kept but not summarized, and long-term memories are only those your application adds. `openai`, `anthropic` or `openai_compatible`: that service, with your key. Changes in place.
- `name` (String) The store's name, unique within the database: 1-63 lowercase letters, digits, `-` or `_`, starting with a letter or digit. A database holds at most 20 stores. Changing it makes a new, empty store and deletes this one with everything in it.

### Optional

- `custom_types` (Attributes List) Up to three kinds of memory of your own, besides the built-in `semantic` (facts and preferences) and `episodic` (what happened). The language model is told to extract each, by its description. (see [below for nested schema](#nestedatt--custom_types))
- `dedupe_threshold` (Number) A new memory at least this similar (cosine, above 0 and at most 1) to one the same actor already has is treated as a duplicate. The API uses 0.92 when the store is created without one; left out of the configuration afterwards, the current value is kept.
- `embed_api_key` (String, Sensitive) Your API key for the embedding provider. KiviDB stores it encrypted and never returns it, so Terraform keeps the value you gave in state and cannot detect a key changed elsewhere. Leaving it out on a later apply keeps the stored key, as long as the provider stays the same.
- `embed_base_url` (String) For `openai_compatible` only, and required for it: the https URL its `/embeddings` sits under. Addresses on private or reserved networks are refused.
- `embed_model` (String) The embedding model, e.g. `text-embedding-3-small`. Required unless `embed_provider` is `none`, and not used when it is.
- `extraction_delay_seconds` (Number) How long after a session's last new message long-term memories are extracted from it, 30-3600 seconds. Defaults to 300.
- `keep_recent` (Number) How many of the most recent messages a summary leaves as they are, 1-500, and less than `summarize_after`. Defaults to 12.
- `llm_api_key` (String, Sensitive) Your API key for the language model. Stored encrypted and never returned, like `embed_api_key`, and kept on a later apply that leaves it out, for the same provider.
- `llm_base_url` (String) For `openai_compatible` only, and required for it: the https URL of its OpenAI-style API. Addresses on private or reserved networks are refused.
- `llm_model` (String) The language model, e.g. `gpt-4o-mini`. Required unless `llm_provider` is `none`, and not used when it is.
- `memory_ttl_seconds` (Number) How long a long-term memory is kept, 3600-157680000 seconds (5 years). Defaults to 31536000 (a year).
- `redact_pii` (Boolean) Replace common personal identifiers in a long-term memory before it is stored: email addresses, phone numbers, payment card numbers, US social security numbers and IPv4 addresses each become a marker such as `[email]`. These are patterns, so names and postal addresses are not caught. Defaults to true.
- `session_ttl_seconds` (Number) How long a session's working memory is kept after its last message, 60-2592000 seconds (30 days). Defaults to 3600.
- `summarize_after` (Number) Summarize a session once it holds more than this many messages, 4-1000. Defaults to 40.

### Read-Only

- `created_at` (String) When the store was created.
- `has_embed_api_key` (Boolean) Whether KiviDB holds an API key for the embedding provider.
- `has_llm_api_key` (Boolean) Whether KiviDB holds an API key for the language model.
- `id` (String) `<instance_id>/<name>`, which is also the import id.
- `memory_types` (List of String) Every kind of memory the store keeps: `semantic`, `episodic` and the names in `custom_types`.

### Nested Schema for `custom_types`

Required:

- `description` (String) What to extract as this kind of memory, in plain words, 10-2000 characters. Given to the language model.
- `name` (String) 1-32 lowercase letters, digits and `_`, starting with a letter; not `semantic` or `episodic`, and different from the others.

## Import

Import is supported using the following syntax:

```shell
# Import a store by its database's id and its name. Neither API key is returned
# by the API, so set embed_api_key and llm_api_key in the configuration again.
terraform import kividb_agent_memory_store.support 790df3ae-c064-45f5-b924-9ed89471fd72/support
```
