# kividb_kdb_snapshot (Resource)

A KDB export of a database: its data written out as a portable `.kdb` file,
taken on demand. Unlike a [disk snapshot](disk_snapshot.md), the file can be
downloaded from the console, delivered to a bucket of your own, and loaded into
any KiviDB.

```terraform
# A KDB export of the database, taken once, before something irreversible.
resource "kividb_kdb_snapshot" "before_migration" {
  instance_id = kividb_instance.orders.id
  label       = "before-migration"

  # Copied into the database's export destination too, if it has a verified
  # one (kividb_instance_export). Set false to keep it in KiviDB's storage only.
  deliver = true
}

# A new database made from it, in the same cloud, region and account.
resource "kividb_instance" "orders_copy" {
  name                         = "orders-copy"
  tier                         = "essentials"
  cloud                        = kividb_kdb_snapshot.before_migration.cloud
  region                       = kividb_kdb_snapshot.before_migration.region
  data_size_gb                 = 8
  restore_from_kdb_snapshot_id = kividb_kdb_snapshot.before_migration.id
}
```

## Waiting

The apply waits, for up to an hour, for the file to be written, because an
export still being written cannot be restored from or deleted. Set
`wait_for_ready = false` to return as soon as the export is queued.

If the export fails, the apply fails with its error, and the failed export is
deleted, since it holds no file. If it is still being written when the hour is
up, its id is kept in state and Terraform marks it tainted: it exists, and the
next apply replaces it rather than forgetting it.

## Delivery

When the database has a verified export destination
([`kividb_instance_export`](instance_export.md)), the export is also copied into
that bucket after it is written. That copy is not waited for: `delivery_status`
reads `pending`, or null, until a refresh after it lands. Set `deliver = false`
to keep an export in KiviDB's storage only.

## Destroying

Destroying the resource deletes the export from KiviDB's storage. A copy already
delivered to your bucket is yours and is not touched. An export still being
written is waited for (up to 30 minutes) and deleted when it finishes.

## Restoring

To make a new database from an export, set [`kividb_instance`](instance.md)'s
`restore_from_kdb_snapshot_id` to its `id`. The database must be in the
export's `cloud`, `region` and cloud account. Restoring into an existing
database replaces its data and is not a Terraform operation; do it from the
console or through an assistant.

## Schema

### Required

- `instance_id` (String) The database to export. It must be running.

### Optional

- `deliver` (Boolean) Copy the export into the database's export destination (`kividb_instance_export`), if it has a verified one. Defaults to true. Set false to keep this one in KiviDB's storage only.
- `label` (String) A name for the export, up to 128 characters. The server generates one when this is not set. There is no renaming an export, so changing it takes a new one.
- `wait_for_ready` (Boolean) Wait for the file to be written before the apply returns, for up to an hour. Defaults to true, because an export still being written cannot be restored from or deleted. Delivery to your bucket happens after that and is not waited for; see `delivery_status`.

### Read-Only

- `cloud` (String) Cloud the file is stored in: the database's.
- `cloud_account_id` (String) The cloud account the file is stored in: the database's own. Null for KiviDB's cloud. A database made from this export is placed in this account.
- `cloud_account_name` (String) The name of that cloud account, as the KiviDB console shows it.
- `completed_at` (String) When the file was written.
- `created_at` (String) When the export was requested.
- `delivered_uri` (String) Where the copy was written in your bucket (`s3://...`), once delivered.
- `delivery_error` (String) Why the copy into your bucket failed, as the API reported it.
- `delivery_status` (String) Copy into your bucket: `pending`, `delivered` or `failed`. Null when the export has no destination.
- `expires_at` (String) When KiviDB deletes its copy on its own, if ever. Null for an export taken here: it is kept until destroyed.
- `id` (String) Snapshot id.
- `instance_name` (String) Name the database had when it was exported.
- `region` (String) Region the file is stored in: the database's. A database made from it must be in this region.
- `size_bytes` (Number) Size of the file, once written.
- `status` (String) `creating`, `ready`, `failed`, or `moving` while it is copied to another region.
- `triggered_by` (String) `manual` for an export taken here.

## Import

Import is supported using the following syntax:

```shell
# A KDB snapshot is imported by its id.
terraform import kividb_kdb_snapshot.before_migration 1a2b3c4d-5e6f-4a7b-8c9d-0e1f2a3b4c5d
```
