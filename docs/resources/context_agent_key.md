# kividb_context_agent_key (Resource)

An agent key for a [`kividb_context_model`](context_model.md): what an AI
agent sends, as `Authorization: Bearer kvctx_...`, to call the model's tools
over the Model Context Protocol at `mcp_url`.

```terraform
# A key that sees only one tenant's customers and orders.
resource "kividb_context_agent_key" "acme" {
  model    = kividb_context_model.shop.name
  name     = "acme support agent"
  entities = ["customer", "order"]
  filters = {
    customer = { tenant = "acme" }
  }
}

# What an MCP client needs: the URL, and the key as a bearer token.
output "acme_mcp_url" {
  value = kividb_context_agent_key.acme.mcp_url
}

output "acme_agent_key" {
  value     = kividb_context_agent_key.acme.key
  sensitive = true
}
```

## The key is in state

The API shows the key once, when it is made. The provider keeps it in state as
the sensitive `key`, so anyone who can read the state can read the key. An
imported key's `key` is null: the API cannot show it again.

## Scope

A key sees all of the model's entities unless `entities` limits it. `filters`
adds fixed conditions to every query through the key, which the agent cannot
remove: `{ customer = { tenant = "acme" } }` lets it see only acme's customers.
Only `tag` and `numeric` fields, or the entity's `id_field`, can be filtered,
and a numeric value is written as a string.

## Nothing changes in place

The API cannot change a key, so every change makes a new key and revokes the
old one; an agent still holding the old key is refused from then on. Destroying
the resource revokes the key. A key revoked in the console, or removed with its
model, disappears from state on the next refresh, and the next apply makes a
new one.

## Schema

### Required

- `model` (String) The name of the context model the key is for. A model has at most 50 keys.
- `name` (String) A name for the key, 1-100 characters, so you can tell keys apart in the console.

### Optional

- `entities` (List of String) Only these entities' tools, by name, 1-20 of them. Leave it out for all of the model's entities, including ones added later.
- `filters` (Map of Map of String) Fixed filters per entity, which every query through this key adds and the agent cannot remove: `{ customer = { tenant = "acme" } }` lets the key see only acme's customers. Only `tag` and `numeric` fields (or the entity's `id_field`) can be filtered; a numeric field's value is written as a string, e.g. `"5"`.

### Read-Only

- `created_at` (String) When the key was made.
- `id` (String) The key's id (not the key). Import with `<model>/<id>`.
- `key` (String, Sensitive) The agent key, `kvctx_...`. The API shows it only when it is made, so it is null for an imported key. Anyone with state can read it.
- `key_prefix` (String) The key's first characters, as the console lists it.
- `mcp_url` (String) Where an agent with this key connects over the Model Context Protocol (JSON-RPC over HTTP POST), sending `Authorization: Bearer <key>`.

## Import

Import is supported using the following syntax:

```shell
# Import an agent key by its model's name and the key's id (from the console).
# The key itself is shown only when it is made, so an imported key's `key` is null.
terraform import kividb_context_agent_key.acme shop/3f0c1a52-8b7e-4c1e-9a55-0c2f1e0b8d11
```
