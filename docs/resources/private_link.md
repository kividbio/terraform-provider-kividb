# kividb_private_link (Resource)

Private connectivity to a database: an endpoint service your own network
connects to without crossing the internet -- AWS PrivateLink, Azure Private
Link Service or Google Cloud Private Service Connect, by the database's cloud.

**It is a paid add-on, $25 a month per database**, billed from the moment this
resource is created until it is destroyed. It is not available on the free
tier, and not needed for a database in your own cloud account
(`cloud_account_id`), which is already inside your network; the API refuses
both.

Creating it builds the endpoint service, which takes three to four minutes; the
apply waits for `service_name`, the name you create your endpoint against.
Only the principals in `allowed_principals` may connect to it: an empty list is
a service nobody can reach yet.

With it in place, `public_access_blocked = true` closes the public endpoint
entirely, so the database is reachable only through your private endpoint.

**Destroying this resource turns private connectivity off and stops the
charge.** Endpoints created against it stop working. If public access was
blocked, it is opened again first -- to the addresses in the allowlist, not to
everyone -- because a database with neither path is unreachable, and the API
refuses to leave it that way.

```terraform
# Private connectivity for a database on AWS: $25 a month, from creation until
# destroy. Only the listed AWS accounts may create an endpoint against it.
resource "kividb_private_link" "orders" {
  instance_id        = kividb_instance.orders.id
  allowed_principals = ["arn:aws:iam::123456789012:root"]

  # Once your endpoint works, close the public endpoint entirely.
  public_access_blocked = false
}

# Your side: an interface endpoint in your VPC, in the same region.
resource "aws_vpc_endpoint" "kividb" {
  vpc_id              = var.vpc_id
  service_name        = kividb_private_link.orders.service_name
  vpc_endpoint_type   = "Interface"
  subnet_ids          = var.subnet_ids
  security_group_ids  = [var.security_group_id]
  private_dns_enabled = false
}
```

## Schema

### Required

- `instance_id` (String) The database. **Changing this turns private connectivity off on the old database and on for the new one.**

### Optional

- `allowed_principals` (Set of String) Who may connect, at most 50, in the database's cloud's own terms: on AWS, principal ARNs (`arn:aws:iam::123456789012:root`, `:role/<name>` or `:user/<name>`); on Azure, subscription ids; on Google Cloud, project ids or numbers. The API refuses one that is not valid for the database's cloud, naming it. Changed in place.
- `public_access_blocked` (Boolean) Close the public endpoint, so the database is reachable only through private connectivity. Applied once the endpoint service exists. Changed in place.
- `wait_for_ready` (Boolean) Wait for the endpoint service to be built (three to four minutes, at most 20) before the apply completes. On by default, because `service_name` is unknown until then. With `false`, `public_access_blocked` is still applied only after the service exists, so the apply waits anyway when it is set.

### Read-Only

- `id` (String) The database's id.
- `ports` (List of Object) The ports the service listens on: `port`, its `role` (`primary`, `replicas` or `replica`), whether it is `tls`, and a `label`. A replica's port is listed only while that replica exists. (see [below for nested schema](#nestedatt--ports))
- `region` (String) The region the endpoint service is in; your endpoint must be in the same one.
- `service_name` (String) What to create your endpoint against: the endpoint service name on AWS, the Private Link Service alias on Azure, the service attachment on Google Cloud. Null until it is built.
