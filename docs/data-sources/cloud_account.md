# kividb_cloud_account (Data Source)

A cloud account of your own that KiviDB databases can run in. Look it up by
`name` or `id`, then pass its `id` to
[`kividb_instance`](../resources/instance.md)'s `cloud_account_id`.

Accounts are connected in the KiviDB console, under **Dashboard → Settings →
Cloud accounts**, not from Terraform: connecting one grants KiviDB access to
the account, and that is done by a person who is signed in. There is no
resource for it.

AWS accounts and Google Cloud projects are supported. Azure is coming soon.

```terraform
# An AWS account connected in the KiviDB console, looked up by the name it was
# given there. Use `id` instead if two accounts share a name.
data "kividb_cloud_account" "production" {
  name = "production"
}

output "cloud_account_regions" {
  value = data.kividb_cloud_account.production.regions
}
```

## Looking up by name

Names are chosen in the console and do not have to be unique. If two connected
accounts share the name you ask for, the lookup fails and lists both ids rather
than guessing — placing a database in the wrong account would put its data
somewhere you did not intend. Look the account up by `id`, or rename one of
them.

## Status

Only a `verified` account can take new databases. Reading one that is `pending`
or `failed` succeeds with a warning, so a plan can still show what it found;
creating a database in it is refused until it is verified. Accounts that were
disconnected are not listed.

## Schema

### Optional

- `id` (String) The account's id. Set this or `name`.
- `name` (String) The name the account was given in the console. Set this or `id`; it must match exactly one account.

### Read-Only

- `aws_account_id` (String) The 12-digit AWS account id, for an AWS account.
- `cloud` (String) The account's cloud: `aws` or `gcp`.
- `gcp_project_id` (String) The project ID, for a Google Cloud project.
- `regions` (List of String) Regions enabled for this account. A database in it must use one of them.
- `status` (String) `verified` once KiviDB has confirmed it can act in the account; `pending` or `failed` otherwise. Only a verified account can take new databases.
