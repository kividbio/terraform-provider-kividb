# kividb_credit_reservations (Data Source)

The organization's credit balance, how much of it is set aside for particular
databases, and every credit reservation, active or not. Reading spends
nothing. It needs an API key with the owner or admin role; a member key is
refused. To make or change a reservation, use
[`kividb_credit_reservation`](../resources/credit_reservation.md).

```terraform
data "kividb_credit_reservations" "all" {}

output "unreserved_dollars" {
  value = data.kividb_credit_reservations.all.unreserved_cents / 100
}

output "unprotected_soon" {
  # Reservations with less than a dollar left.
  value = [for r in data.kividb_credit_reservations.all.reservations : r.instance_name
  if r.status == "active" && r.remaining_cents < 100]
}
```

## Schema

### Read-Only

- `balance_cents` (Number) The whole credit balance, in US cents.
- `reservations` (Attributes List) Every reservation: active ones first, newest first within each. (see [below for nested schema](#nestedatt--reservations))
- `reserved_cents` (Number) What active reservations still hold. Only their own databases can spend it.
- `unreserved_cents` (Number) `balance_cents` less `reserved_cents`: what every database without a reservation runs on. When it runs out, those databases are stopped first.

### Nested Schema for `reservations`

Read-Only:

- `amount_cents` (Number) Everything set aside on it, in cents.
- `consumed_cents` (Number) What the database's charges have drawn from it.
- `created_at` (String) When it was created.
- `deactivated_at` (String) When it was deactivated.
- `deactivated_reason` (String) `user`, or `instance_deleted` when KiviDB deactivated it because its database was deleted.
- `id` (String) The reservation's id.
- `instance_id` (String) The database it is for. Null once that database has been deleted.
- `instance_name` (String) The database's name, or the name it had.
- `instance_status` (String) The database's status. Null once it has been deleted.
- `remaining_cents` (Number) What it still holds.
- `status` (String) `active` or `inactive`. Only an active reservation protects its database.
