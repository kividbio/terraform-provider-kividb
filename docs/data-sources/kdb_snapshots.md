# kividb_kdb_snapshots (Data Source)

KDB exports of your databases, newest first: taken on demand, on a schedule, or
uploaded. Use one's `id` as [`kividb_instance`](../resources/instance.md)'s
`restore_from_kdb_snapshot_id` to make a new database from it. Deleted exports
are not listed.

```terraform
# The ready KDB exports of one database, newest first.
data "kividb_kdb_snapshots" "orders" {
  instance_id = "790df3ae-c064-45f5-b924-9ed89471fd72"
  status      = "ready"
}

# Make a new database from the newest one.
resource "kividb_instance" "orders_restored" {
  name                         = "orders-restored"
  tier                         = "essentials"
  cloud                        = data.kividb_kdb_snapshots.orders.snapshots[0].cloud
  region                       = data.kividb_kdb_snapshots.orders.snapshots[0].region
  data_size_gb                 = 8
  restore_from_kdb_snapshot_id = data.kividb_kdb_snapshots.orders.snapshots[0].id
}
```

## Schema

### Optional

- `instance_id` (String) List only this database's exports. Unset, every export in the organization is listed, including those of databases since deleted.
- `status` (String) List only exports with this status: `creating`, `ready`, `failed` or `moving`. Only a `ready` export can be restored from.

### Read-Only

- `snapshots` (Attributes List) The exports, newest first. (see [below for nested schema](#nestedatt--snapshots))

### Nested Schema for `snapshots`

Read-Only:

- `cloud` (String) Cloud the file is stored in.
- `cloud_account_id` (String) The cloud account it is stored in; null for KiviDB's cloud. A database made from it is placed in this account.
- `cloud_account_name` (String) The name of that cloud account.
- `completed_at` (String) When the file was written.
- `created_at` (String) When the export was requested.
- `delivered_uri` (String) Where the copy was written in your bucket, once delivered.
- `delivery_status` (String) Copy into your own bucket: `pending`, `delivered` or `failed`; null when none.
- `expires_at` (String) When KiviDB deletes it on its own. Null when it is kept until deleted.
- `id` (String) Snapshot id.
- `instance_id` (String) The database it was exported from. Null once that database is deleted.
- `instance_name` (String) Name the database had when it was exported.
- `label` (String) The export's name.
- `region` (String) Region the file is stored in. A database made from it must be in this region.
- `size_bytes` (Number) Size of the file, once written.
- `status` (String) `creating`, `ready`, `failed` or `moving`.
- `triggered_by` (String) `manual`, `schedule` or `free_tier_expiry`.
