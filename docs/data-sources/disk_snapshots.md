# kividb_disk_snapshots (Data Source)

Disk snapshots of your databases, newest first, scheduled ones included. Use
one's `id` as [`kividb_instance`](../resources/instance.md)'s
`restore_from_snapshot_id` to make a new database from it. Deleted snapshots
are not listed.

```terraform
# The finished disk snapshots of one database, newest first -- scheduled ones
# included, which no configuration created.
data "kividb_disk_snapshots" "orders" {
  instance_id = "790df3ae-c064-45f5-b924-9ed89471fd72"
  status      = "ready"
}

output "latest_disk_snapshot" {
  value = try(data.kividb_disk_snapshots.orders.snapshots[0].id, null)
}
```

## Schema

### Optional

- `instance_id` (String) List only this database's snapshots. Unset, every snapshot in the organization is listed, including those of databases since deleted.
- `status` (String) List only snapshots with this status, for example `ready`. Only a finished snapshot can be restored from.

### Read-Only

- `snapshots` (Attributes List) The snapshots, newest first. (see [below for nested schema](#nestedatt--snapshots))

### Nested Schema for `snapshots`

Read-Only:

- `cloud` (String) Cloud the snapshot is stored in.
- `cloud_account_id` (String) The cloud account it is stored in; null for KiviDB's cloud. A database made from it is placed in this account.

- `completed_at` (String) When the copy finished.
- `created_at` (String) When the snapshot was requested.
- `expires_at` (String) When KiviDB deletes it on its own under the retention policy. Null when it is kept until deleted.
- `id` (String) Snapshot id.
- `instance_id` (String) The database it was taken from. Null once that database is deleted.
- `instance_name` (String) Name of the database it was taken from.
- `label` (String) The snapshot's name.
- `region` (String) Region the snapshot is stored in. A database made from it must be in this region.
- `size_gb` (Number) Size of the captured volume, once known.
- `status` (String) Snapshot state as the server reports it, such as `creating`, `ready` or `failed`.
- `triggered_by` (String) What took it, such as `manual` or `schedule`.
