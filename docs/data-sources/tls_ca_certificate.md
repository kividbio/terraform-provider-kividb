# kividb_tls_ca_certificate (Data Source)

The CA certificate that signs a database's TLS certificate, for a client to trust when it connects with TLS (`tls_enabled` on `kividb_instance`).

It is the same certificate for every database KiviDB runs, so reading it for one database gives the CA for all of them. It is public, not a secret: it is what clients check the server against, and holding it lets nobody in.

```terraform
# The CA a client trusts when it connects to a database with TLS.
data "kividb_tls_ca_certificate" "kividb" {
  instance_id = kividb_instance.cache.id
}

# For example, hand it to an application as a file.
resource "local_file" "kividb_ca" {
  filename = "${path.module}/kividb-ca.pem"
  content  = data.kividb_tls_ca_certificate.kividb.certificate_pem
}
```
